DESCRIPTION: This program implements a simple rule-based chatbot using Python and the NLTK library.It uses regular expressions to identify patterns in user input.Each pattern is paired with predefined responses stored in a list.When the user types a message, the chatbot searches for a matching pattern.If a match is found, it selects and displays an appropriate response.
The chatbot can respond to greetings, emotions, jokes, and basic questions.It also handles study related queries and simple personal questions.Reflections are used to make conversations sound more natural.A fallback response is provided when the input is not understood.The Chat class manages input processing and response generation.The chatbot runs continuously in the terminal interface.It interacts with the user until the “quit” command is entered.This chatbot does not use machine learning or AI models.It is fully rule-based and easy to understand.The project is suitable for beginners learning NLP concepts.
